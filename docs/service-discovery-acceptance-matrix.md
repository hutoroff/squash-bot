# Repository-local acceptance evidence (discovery + reliable booking)

This is a trace from [discovery design §15](service-discovery-design.md#15-test-and-acceptance-plan), [§10.1 management gates](service-discovery-design.md#management-acceptance-gates), and [booking design §12](booking-reliability-design.md#12-acceptance-and-fault-injection-matrix) to *actual assertions*. “Partial” means the named tests exercise only the stated seam; it is **not** an acceptance sign-off. **Step 12 repository-local fixtures are complete, not operationally signed off:** simulated caller reconstruction is not a process kill, and independent tests of two services are not a cross-service, provider-side exactly-once guarantee. Tests never contact Telegram or Eversports. Production cutover, inventory/import, Grafana provisioning and real notification delivery remain owner gates.
