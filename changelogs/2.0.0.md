## Features
- When reporting a result, choose the score type: points (for example `11:9`) or games/sets won (for example `3:0`)
- Removing the last court from a game now calls the game off
- Server owners can switch experimental features on or off globally or per group in the Web UI
- Court bookings are more reliable and recover cleanly after restarts
